Classificació musical

El menú Classificació reuneix els criteris que OSAP utilitza per organitzar les obres. Cada entrada permet explorar el catàleg des d’una perspectiva musical diferent i consultar els valors utilitzats.

Per a què serveix? La classificació ajuda a trobar repertori segons el context històric, el tipus de música, les referències de catàleg, la instrumentació o la formació. No totes les obres tenen necessàriament totes aquestes dades; una absència o una assignació dubtosa pot reflectir informació incompleta a les fonts.

1. Èpoques

Presenta els períodes històrics utilitzats per situar les obres en el temps. Les denominacions i els límits cronològics són orientatius: els períodes musicals se solapen i no sempre hi ha una data universal per separar-los.

Problemes que pots trobar: una obra pot situar-se en una transició entre èpoques; la data de composició pot ser desconeguda o discutida, i l’època d’una obra no sempre coincideix exactament amb la vida del compositor. Si una assignació sembla incorrecta, indica l’obra concreta i aporta una font que justifiqui la correcció.

2. Gèneres

Agrupa obres per tipus o famílies musicals. El gènere descriu una característica musical o una tradició; no s’ha de confondre necessàriament amb la forma de l’obra, la seva època o el conjunt que la interpreta.

Problemes que pots trobar: algunes obres combinen gèneres, els noms varien segons la tradició o la font, i un mateix terme pot tenir significats històrics diferents. La classificació disponible pot ser més general que la descripció d’un especialista.

3. Catàlegs

Reuneix els sistemes de numeració i les referències temàtiques que permeten identificar obres dins d’un catàleg, com BWV, Köchel o Hoboken. Una referència de catàleg ajuda a distingir obres que comparteixen títol i a reconèixer denominacions alternatives.

Problemes que pots trobar: un número pot variar entre edicions o revisions d’un catàleg; una obra pot tenir més d’una referència, i una referència importada pot ser incompleta o estar mal transcrita. Comprova la sigla i la numeració completes, no només el número.

4. Instruments

Organitza la informació d’instrumentació i veus associada a les obres. Permet explorar el repertori per instrument o família instrumental quan aquestes dades estan registrades.

Problemes que pots trobar: la font pot descriure una plantilla incompleta, utilitzar sinònims, agrupar els instruments de manera diferent o confondre l’instrument original amb una adaptació posterior. Que un instrument no hi aparegui no demostra, per si sol, que l’obra no l’utilitzi.

5. Conjunts

Descriu formacions vocals o instrumentals, com ara cor, quartet, orquestra o altres combinacions. Es refereix a la plantilla o agrupació per a la qual està destinada la música, que pot ser diferent d’un instrument aïllat.

Problemes que pots trobar: una obra pot tenir diverses versions per a formacions diferents; els noms de les agrupacions no sempre són equivalents, i algunes fonts descriuen la plantilla amb molt detall mentre que d’altres només n’indiquen una categoria general.

Com interpretar una classificació dubtosa

  1. Obre l’obra concreta i comprova quina dada hi consta.
  2. Distingeix entre una dada absent i un valor que sembla incorrecte.
  3. Consulta, si està disponible, la font original o una edició fiable.
  4. Envía la incidencia desde Amics i comunitat musical, indicant l’obra, el valor actual, el valor proposat i les proves.

La classificació reflecteix les dades que OSAP ha pogut reunir. No totes les obres disposen d’informació completa i les categories poden requerir una revisió.
