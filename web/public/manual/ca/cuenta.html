Compte, accés i activitat

Aprèn a iniciar sessió, crear un compte, gestionar el nom visible i consultar l’activitat personal.

Navegar sense compte

Moltes pàgines del catàleg es poden consultar sense registrar-se. Algunes funcions requereixen iniciar sessió.

Crear un compte

Fes servir el botó d’inici de sessió i segueix les instruccions. No comparteixis les credencials amb el suport.

Nom visible i activitat

El nom del compte i l’autorització per aparèixer públicament com a col·laborador poden ser coses diferents. Tanca la sessió en dispositius compartits.
