Other tools and information pages

This section covers supplementary features that are not explained in the main pages of the guide.

1. Resolve a work or find better representations

When a work has no usable file or its versions are unsatisfactory, an option may appear to search connected repositories for additional representations. The tool may show the process status or progress. Starting a search does not guarantee a better file will be found; this depends on available sources and each provider’s response.

2. Candidate works and matches

If OSAP shows records that may refer to the same work, compare the title, authorship, catalogue references, source and available evidence. A suggested match is not a definitive confirmation when significant differences remain.

3. Project information and legal pages

La sección About explains OSAP’s purpose and how the project generally works. The footer links to the legal notice, privacy policy and cookie policy.
