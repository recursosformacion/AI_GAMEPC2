Classification musicale

El menú Classificació réunit les critères utilisés par OSAP pour organiser les œuvres. Chaque entrée permet d’explorer le catalogue sous un angle musical différent et de consulter les valeurs utilisées.

À quoi cela sert-il ? La classification aide à trouver du répertoire selon le contexte historique, le type de musique, les références de catalogue, l’instrumentation ou la formation. Toutes les œuvres ne disposent pas nécessairement de toutes ces données ; une absence ou une attribution incertaine peut refléter des informations incomplètes dans les sources.

1. Époques

Présente les périodes historiques utilisées pour situer les œuvres dans le temps. Les appellations et les limites chronologiques sont indicatives : les périodes musicales se chevauchent et il n’existe pas toujours de date universelle pour les distinguer.

Problèmes possibles : une œuvre peut se situer à la transition entre plusieurs époques ; sa date de composition peut être inconnue ou discutée, et son époque ne coïncide pas toujours exactement avec la vie de son compositeur. Si une attribution semble incorrecte, indiquez l’œuvre concernée et une source justifiant la correction.

2. Genres

Regroupe les œuvres par types ou familles musicales. Le genre décrit une caractéristique musicale ou une tradition ; il ne doit pas nécessairement être confondu avec la forme de l’œuvre, son époque ou l’ensemble qui l’interprète.

Problèmes possibles : certaines œuvres mêlent plusieurs genres, les noms varient selon la tradition ou la source et un même terme peut avoir différentes significations historiques. La classification disponible peut être plus générale que la description d’un spécialiste.

3. Catalogues

Rassemble les systèmes de numérotation et les références thématiques permettant d’identifier les œuvres dans un catalogue, comme BWV, Köchel ou Hoboken. Une référence aide à distinguer des œuvres portant le même titre et à reconnaître les appellations alternatives.

Problèmes possibles : un numéro peut varier selon les éditions ou les révisions d’un catalogue ; une œuvre peut avoir plusieurs références et une référence importée peut être incomplète ou mal transcrite. Vérifiez le sigle et la numérotation complète, pas seulement le numéro.

4. Instruments

Organise les informations d’instrumentation et de voix associées aux œuvres. Permet d’explorer le répertoire par instrument ou famille instrumentale lorsque ces données sont enregistrées.

Problèmes possibles : la source peut décrire un effectif incomplet, utiliser des synonymes, regrouper les instruments différemment ou confondre l’instrument d’origine avec une adaptation ultérieure. L’absence d’un instrument ne prouve pas à elle seule que l’œuvre ne l’utilise pas.

5. Ensembles

Décrit les formations vocales ou instrumentales, comme un chœur, un quatuor, un orchestre ou d’autres combinaisons. Il s’agit de l’effectif ou du groupe auquel la musique est destinée, qui peut différer d’un instrument isolé.

Problèmes possibles : une œuvre peut avoir plusieurs versions pour différentes formations ; les noms des ensembles ne sont pas toujours équivalents et certaines sources décrivent l’effectif en détail, tandis que d’autres n’indiquent qu’une catégorie générale.

Comment interpréter une classification incertaine

  1. Ouvrez l’œuvre concernée et vérifiez la donnée attribuée.
  2. Distinguez une donnée absente d’une valeur qui semble erronée.
  3. Consultez, si elle est disponible, la source d’origine ou une édition fiable.
  4. Envía la incidencia desde Amis et communauté musicale, indicando la obra, el valor actual, el valor propuesto y la evidencia.

La classification reflète les données qu’OSAP a pu réunir. Les informations ne sont pas complètes pour toutes les œuvres et les catégories peuvent nécessiter une révision.
